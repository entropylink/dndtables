Settlement sizes & how many vendors

Traveling vendors are determined each week (or day). The total can be 0. Duplicates are allowed: two selling almost the same thing create competition and push prices down.

Permanent variety vendors d100

Table adjusted to the selected size. Roll 1d100 for each variety stall shown in the sizes table. Reroll if a duplicate comes up.

Traveling vendors d100

First determine how many with the die from the sizes table (min. 0). Then roll 1d100 for each one here. Duplicates are valid.

Price variation & competition d12

Roll 1d12 per vendor for its price level vs. the book's base price. If two or more sell the same category, also apply −10% for competition.
